# 产品设计环境

产品在这里修改页面、交互和显示状态，只使用 mock 数据。页面代码与正式前端独立，设计起点来自已上线版本。

## 关键入口

- [mockend](../mockend/README.md)：切换场景、编辑模拟数据。
- [PRD模板](../docs/workflow/templates/prd.md)与[设计交接模板](../docs/workflow/templates/design-handoff.md)。
- [本目录规则](AGENTS.md)。

## 怎么用

从当前底稿做增量设计，演示操作、跳转和相关异常状态；交付时固定界面、PRD 和 mock 场景版本，交给研发实现。

下一次上线后再更新底稿，保留尚未交付的设计，避免覆盖正在进行的工作。
