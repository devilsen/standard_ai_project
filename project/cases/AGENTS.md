# 业务案例

- 接需求时主动检查已有案例，向用户索取缺少的代表性输入、业务目标和授权；不要求用户承担测试设计，已有输入不重复索要。
- 敏感原件放在项目授权的存储，仓库只保留说明、定位方式和获准保存的摘要。没有授权不读取其他客户材料。
- 模型文档输出优先用内容、来源、顺序和版式等语义判定；字节哈希用于输入冻结/传输完整性，不要求生成文件全哈希恒定。
- Agent在执行前从已批准PRD、原文件和领域规则独立制定研发预期、允许差异及失败条件，标明依据并冻结；不将被测模型输出当答案，也不把研发预期当作用户批准。涉及产品选择而来源无法确定时再澄清；最终case及结果由用户复核。
- 真实案例缺失时可用明确标记的合成样例推进独立开发，但最终真实验收保持未执行。
- 不更改案例期望来迎合当前实现。案例变更记录原因、确认来源及受影响测试。
