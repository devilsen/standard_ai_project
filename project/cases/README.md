# 用户验收案例

这里说明用什么输入、经过哪些操作、应该得到什么结果，让设计、开发和验收有共同依据。

## 关键入口

- [案例模板](../docs/workflow/templates/case.md)。
- [测试计划](../docs/workflow/templates/test-plan.md)与[流程测试](../e2e/README.md)。
- [本目录规则](AGENTS.md)。

## 怎么用

接需求时就收集用户输入与预期，注明允许差异和失败条件；优先复用已有案例。执行后记录实际结果和差异，不修改预期来迁就实现。

敏感原件放在授权存储中，这里保留说明与引用；合成案例要明确标注。
