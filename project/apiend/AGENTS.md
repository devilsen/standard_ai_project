# API定义与展示

- 本模块统一管理接口定义与展示；定义位于 `apiend/contracts/`，展示实现采用后位于 `apiend/src/`，不再使用项目顶层contracts目录。
- 从本模块 `contracts/` 中的 OpenAPI 和示例直接生成页面；用途、字段、错误和示例只维护一处。修改定义时同时读取该子目录AGENTS.md。
- 模块页面区分已确认接口、提案与尚未实现部分，不把文档可显示视为服务可调用。
- 文档默认使用合成示例；如提供“试调用”，默认目标为 mock，连接真实服务须显式选择且不得内置密钥。
- 契约变更后验证文档可生成、示例可解析及错误描述可见。
- 不在 apiend 再实现鉴权、业务规则或后端代理平台。
