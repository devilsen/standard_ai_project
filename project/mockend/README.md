# 模拟数据工作台

这里管理设计环境的数据和场景，例如空列表、执行中、成功、失败。产品可以修改数据，直接查看对应界面。

## 关键入口

- [designend](../designend/README.md)：查看场景效果。
- [接口契约](../apiend/contracts/README.md)：场景数据使用同一套字段含义。
- [本目录规则](AGENTS.md)。

## 怎么用

按模块选择场景，编辑并保存 `data.json`，再到 designend 操作验证。提交、重试等行为由模拟实现处理；测试前可以重置场景。

采用模板时需实现编辑工作台与保存能力，当前目录仅提供约定。数据使用合成样例，不放真实凭据或客户原件。
