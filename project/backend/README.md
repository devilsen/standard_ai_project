## 怎么用

先看已有模块和调用链，再选择一条行为写测试、完成最小实现。保留业务单测、真实数据库集成和外部对接用例；测试环境开发修复并验证通过、用户确认后才发布staging；迁移和部署沿用项目现有规则。

新增抽象要解决当前问题，不为遵循架构术语堆叠层级。实际运行命令从项目配置中登记。
