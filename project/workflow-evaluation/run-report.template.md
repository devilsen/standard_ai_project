# 一轮Skill比较记录

## 固定条件

- 原版本文件/提交/哈希：
- 候选版本文件/提交/哈希：
- 本轮唯一改动及对应失败依据：
- 模型、推理设置、工具/权限、宿主、项目规则版本：
- 场景输入版本、隔离工作区、重复次数：
- 评分者及是否与执行者独立：

## 实际结果

| 场景/运行 | 原版本分数及致命项 | 候选分数及致命项 | 实际产物/工具证据 | 未执行或条件差异 |
|---|---|---|---|---|
| | | | | |

## 判断

- 原有失败是否修复，证据是什么：
- 保留变体是否退化，最低分与致命问题是否变化：
- 用户需要补充/纠正哪些内容，是否减少了实质返工：
- 是否只是增加询问次数/文档数量而没有改善行为：
- 候选是否值得采用、仍存风险、下次只调整什么：

不把一次样本结果推广为100%可靠；评分不足或实际行为未运行时明确保留未验证结论。
