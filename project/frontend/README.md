# 正式前端

这里是用户实际使用的页面，连接真实后端。研发根据产品交付的界面和 PRD，在这里完成正式实现。

## 关键入口

- [designend](../designend/README.md)：查看产品设计与交互。
- [接口契约](../apiend/contracts/README.md)：确认数据和错误含义。
- [浏览器测试](../e2e/README.md)与[本目录规则](AGENTS.md)。

## 怎么用

先定位本次交接的设计版本，再修改对应业务模块，复用现有组件和样式。完成后运行模块测试与相关浏览器用例。实际启动、测试命令写在本次任务记录中。

测试环境验证通过并获用户确认后，才发布staging；验证后同步下一轮设计底稿。产品修改设计时，不直接覆盖这里。
