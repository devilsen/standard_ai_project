# 用户验收案例

- 案例名称 / 用户与业务背景：
- 输入文件位置、授权、摘要与版本：
- 前置状态与操作步骤：
- 预期输出、内容、顺序、版式、来源：
- 允许差异（例如动态日期、非固定分页、生成ID）：
- 失败条件及异常恢复预期：
- 外部服务、预计成本/副作用与授权范围：
- 独立预期制定者、PRD/原文依据、冻结时间（执行前）；用户已给定/最终待复核分别标记：

## 验证方法

哪些可自动断言，哪些需要人工判断；Word/PDF兼容目标是什么。输入哈希用于冻结/传输，不用生成文件字节一致代替语义正确。

## 执行结果

实现提交、环境、任务、实际产物、逐项预期/实际差异、通过/失败/未执行、未覆盖内容；模拟材料及人工步骤明确标注。没有真实运行时明确写未执行。

引用原task/test-plan中的累计开始时间、轮次/耗时、修复与复验记录；不为每轮重建case或重置预算。用户最终复核结论与研发自检分开记录。
