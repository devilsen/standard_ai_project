# 工作记录模板

按任务需要使用下面的模板。已有等价文档可以直接引用，不必每次复制全部文件。

| 模板 | 什么时候用 |
|---|---|
| [任务记录](task.md) | 记录依据、当前进度、决定和下一步 |
| [PRD](prd.md) | 说明目标、行为与业务规则 |
| [设计交接](design-handoff.md) | 产品把界面与PRD交给研发 |
| [用户案例](case.md) | 固定输入、预期和允许差异 |
| [工作切片](slice.md) | 拆出一个可独立验证的行为 |
| [测试计划](test-plan.md) | 将行为对应到测试方式 |
| [交付记录](delivery.md) | 记录真实结果、缺口和发布状态 |
| [IM消息](im-message.md) | 提问、测试后私聊请验收、最后通知用户和默认群 |

使用时填写本次事实、删除无关项，保留原文档引用。完整步骤见[工作流](../workflow.md)。
