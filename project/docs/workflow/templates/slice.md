# 一个可验收的切片

- 标题：用用户行为或可验证能力命名
- 来源：已交接设计 / PRD行为 / 接口 / case
- 交付后新增的可观察结果：
- 范围：页面、API、后端、数据、测试，按实际列出
- 真实阻塞依赖（无则写无）：
- 未决产品问题（如影响本片则不能擅自填充）：

## 验收条件

Given什么前置状态，When什么操作，Then看到/持久化/输出什么；包含本片关键异常。

## 工作顺序

1. 选当前行为与公共测试边界。
2. 写测试并确认预期失败原因。
3. 最小实现、运行聚焦检查。
4. 前后端集成、相关回归、代码质量检查。
5. 演示结果并记录证据/缺口。

## 测试与完成标准

- 单测 / 集成 / 契约 / 浏览器 / 真实case分别覆盖什么：
- 实际命令与工作目录：
- 通过条件和未执行项：
- 后续重构或范围变化：

不把“代码已写”“接口200”“组件可见”单独作为本片完成。
